# MGM Cam - 3D Mechanical Assembly & Inspection System (Part S145 65)

Interactive 3D WebGL / Three.js CAD model and mechanical assembly visualizer for **MGM Cam ()**:

## Engineering Specifications
- **Seamless Single Cam Body**: Unified continuous solid profile with no split line or visible seams.
- **Counterbore Socket**: Depth 3.6mm, diameter 50.4mm with precision internal pilot registration.
- **Continuous Shaft Through-Bore**: 24mm diameter fully open bore passing clear through both cam and flange.
- **Mating Retaining Flange**: 10.8mm thickness with concentric spigot neck (3.5mm depth) for zero-gap assembly.
- **Flush Retaining Detent Pin**: Transverse detent assembly (9.6mm diameter) contained flush inside the flange without bulging.
- **4x Fasteners**: Counterbored hex socket head bolts clamping the assembly.

## Controls & Interaction
- **Stationary Default**: Manual orbit and zoom via mouse or touch gestures with smooth physics damping.
- **Exploded View Slider**: Smooth axial disassembly and assembly.
- **CAD Camera Presets**: Isometric, Front Face, Mating Neck, and Rear Profile.
- **Ultra-Compact UI**: Minimalist, responsive industrial CAD control panel.
