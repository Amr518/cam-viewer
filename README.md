# MGM Cam - 3D Mechanical Assembly & Inspection System (Part S145 65)

Interactive 3D WebGL / Three.js mechanical engineering inspection and assembly visualizer for part :
- **Rear Cam Base**: Teardrop eccentric cam profile with recessed counterbore cavity and stamped serial mark.
- **Front Retaining Flange**: Solid circular disc with central shaft bore and 4x counterbored fastener holes.
- **Spigot Collar Neck**: Mating neck protruding from the flange into the recessed cam socket for precision concentric pilot registration.
- **Lateral Detent Assembly**: Stepped brass sleeve with milled notch and black socket cap screw.
- **Failure Analysis Mode**: Realistic jagged through-wall fatigue crack between the shaft bore and transverse hole.
